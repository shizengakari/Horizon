# Horizon

個人による学習管理システム（LMS）の REST API 通信およびデスクトップ UI アーキテクチャの検証・研究を目的として開発された、個人用リファレンス実装です。

- **個人開発・学習用リファレンス**: 本リポジトリのソースコードは、ローカル環境における非同期通信制御、キャッシュ機構、および Tauri / Rust ベースのデスクトップ UI 設計の技術検証・個人学習を目的として公開されています。
- **サードパーティ製サービスの非提供**: 本プロジェクトは、不特定多数のエンドユーザーに向けた商用・非商用のサードパーティ製クライアントサービスを提供するものではなく、第三者に対してアクセストークンの手動発行や提供・共有を求めるものではありません。
