# Horizon

個人用として開発しているデスクトップアプリのソースコードです。

## データ管理について

設定した URL やトークンなどの情報は、すべてローカル PC 内（`AppData/Roaming/Horizon`）に暗号化して保存されます。外部のサーバーへ送信されることはありません。
